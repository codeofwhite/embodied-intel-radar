# 如何用公开资料理解具身智能岗位

本文是岗位阅读框架，不是当前就业市场排名或作者的私人求职计划。

| 方向 | 阅读招聘要求时关注 | 可准备的项目证据 |
|---|---|---|
| 机器人数据与评测 | 数据格式、质量、标注、闭环和评估职责 | 可追溯采集、质量报告、下游使用结果 |
| 仿真与合成数据 | 引擎、任务实现、传感器、验证要求 | 可复现实验、环境误差和真实适用边界 |
| 三维视觉 | RGB-D、点云、重建、定位要求 | 数据集、误差统计和失败案例 |
| 控制与学习 | 运动控制、模仿学习、强化学习要求 | 原生任务评估、成功率和恢复能力 |
| AI 工程与部署 | 推理、服务、数据平台和可靠性要求 | 性能、资源消耗和可运行系统 |

这些分类对应采集器能力分组，不能据此断言哪个方向岗位最多、薪资最高或工作最轻松。

## 从来源到结论

1. 在 collector/company_registry.json 与 collector/config.json 中找到官网及招聘入口。
2. 打开原页确认发布时间、城市、职级、职责、是否仍可投递。
3. 将事实、来源及日期单独记录；个人解释注明为判断。
4. 将项目经历对应到具体职责，说明自己负责的部分、成果和验证范围。
5. 工作强度、团队稳定性等仅靠岗位文本通常无法判断，应通过面试和多来源核实。

## 历史资料

collector/market_evidence.csv 保留历史统计期间与链接，包括行业报告转载和媒体报道。这些数字没有在本次公开整理中重新核验，因此本文不引用它们得出行业增长或竞争结论。公司目录也不是实时招聘名单。更新分析时应优先补充官方来源、报告原文与访问日期。
